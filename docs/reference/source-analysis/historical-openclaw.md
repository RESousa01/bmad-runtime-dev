# Historical OpenClaw source analysis

OpenClaw is historical comparison only. It is not the current comparable coding-agent reference
and its findings must not be relabelled as OpenCode findings.

The integrated snapshot contains 12,807 files, which does not match the completeness claims in
the legacy reviews. No immutable upstream commit and approved storage locator are locked.
Detailed source citations therefore remain blocked.

The preserved reviews may explain earlier research themes, but they do not prescribe Forge
runtime, provider, security, or deployment behavior.
