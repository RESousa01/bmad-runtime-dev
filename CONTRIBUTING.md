# Contributing to Forge

Start with [Forge team documentation](docs/README.md), then follow the
[contribution guide](docs/development/contribution-guide.md).

Before changing source:

1. Confirm the branch, worktree, HEAD, and dirty state.
2. Identify the source/test authority and any accepted ADR.
3. Choose a bounded task and preserve unrelated changes.
4. Run the narrowest relevant check first.
5. Update current docs only when behavior, decisions, pins, gates, or operating procedures change.
6. Run the required product and documentation gates separately.

Plans, reviews, audits, and agent reports are not completion proof. A change is complete only when
its named acceptance evidence is fresh and reproducible.

See [documentation policy](docs/development/documentation-policy.md) for metadata and lifecycle
rules.
